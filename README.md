# 🏧 ATM Interface (Java)

## 📌 Project Overview

The **ATM Interface** is a Java console-based application that simulates basic ATM banking operations. The system allows users to log in using their **User ID and PIN** and perform different banking transactions such as withdrawing money, depositing money, transferring funds, and viewing transaction history.

This project demonstrates the use of **Object-Oriented Programming (OOP)** concepts in Java such as classes, objects, encapsulation, and collections. It also shows how user authentication and simple banking logic can be implemented using Java.

---

## ✨ Features

* 🔐 User Login Authentication (User ID & PIN)
* 💰 Withdraw Money
* 💳 Deposit Money
* 🔁 Transfer Money to Another Account
* 📜 View Transaction History
* 🚪 Exit ATM System

---

## 🛠️ Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
